# Configuration

Everything is configured with environment variables, read from `.env` (copy
[`.env.example`](../.env.example), which is the single source of truth and has the defaults). Change
a value, then `docker compose up -d` (or `make up`) to apply it. Provider keys can also be saved in
the app (Settings › Integrations); a key saved there wins over `.env` for your account.

The API fails fast at start with a readable message if a required value is missing or invalid.

## Minimal and full stack

| | `make up` (minimal) | `make up-full` (full) |
| --- | --- | --- |
| Services | `api`, `worker`, `beat`, `web`, `postgres`, `redis` | the six, plus `kokoro` (profile `kokoro`), Langfuse: `langfuse-web`, `langfuse-worker` and its Postgres, ClickHouse and Redis (profile `langfuse`), and `s3` (profile `minio`) |
| Memory (approx.) | 1 GB | 6 GB (ClickHouse and Kokoro are the big ones) |
| Disk (approx., images + empty data) | 2 GB | 10 GB (Kokoro downloads its model on first start) |
| Voices | needs an ElevenLabs, OpenAI or OpenRouter key | also free local voices (Kokoro) |
| Tracing | off | Langfuse on <http://localhost:3000>, see [langfuse](langfuse.md) |
| Media | local volume | local volume, or the bundled S3-compatible store, see [storage](storage.md) |

Pick the **minimal** stack when you bring API keys (or a local model server) and want the lightest
install. Pick the **full** stack to run without paid keys, to look at traces, or to try S3.
Starting the full stack does not turn S3 or tracing on by itself: set the `STORAGE_BACKEND`/`S3_*`
and `LANGFUSE_*` values in `.env` as the linked pages describe.

Which optional services `make up-full` starts is the make variable `BYOP_PROFILES` (compose profile
names, default `kokoro langfuse minio`): `BYOP_PROFILES="kokoro" make up-full`. It also applies to
`make build-full` and `make logs-full`. `make up-kokoro`, `make up-minio` and `make up-langfuse`
are shortcuts for one profile. `make down` stops every BYOP container whichever profile started it
and keeps the data; `make down-v` also deletes the volumes (database, media, Langfuse) after a
five-second warning.

Kokoro only counts as a configured voice provider when its server is part of the stack:
`make up-full`/`make up-kokoro` set `KOKORO_BASE_URL` to the bundled service for the containers, a
minimal stack leaves it empty, and the app also checks that the server answers (a configured but
dead URL is ignored). With no voice provider the dashboard checklist and the speakers step of the
show wizard say how to get one.

## Core

| Variable | Default | |
| --- | --- | --- |
| `BYOP_SECRET_KEY` | *(generated by `make up`)* | At least 16 characters. Signs session cookies and encrypts provider keys stored in the database. **Keep it and back it up**: without it stored keys cannot be read. Make one with `openssl rand -hex 32`; rotating it: [security](security.md) |
| `BYOP_SESSION_HOURS` | `168` | How long a login lasts |
| `BYOP_ADMIN_EMAIL` | `admin@example.com` | The admin account, created on first start |
| `BYOP_ADMIN_PASSWORD` | `change-me-now` | Its initial password (hashed into the database; never overwritten once the user exists, change it in the app). **Change it before exposing the app** |
| `PUBLIC_BASE_URL` | `http://localhost:8080` | Where the app is reachable from outside. Builds the absolute addresses in the podcast feed ([feed](feed.md)); podcast apps need public https. Secure cookies are used when it starts with `https://` |
| `BYOP_WEB_PORT` | `8080` | Host port of the web UI |
| `BYOP_VERSION` | empty | Run a published release (for example `0.1.0`) instead of building from source: [releasing](releasing.md) |
| `LOG_LEVEL` | `INFO` | `DEBUG`, `INFO`, `WARNING` or `ERROR`; logs are JSON with a request id |

## Infrastructure

| Variable | Default | |
| --- | --- | --- |
| `DATABASE_URL` | `postgresql+asyncpg://byop:byop@postgres:5432/byop` | PostgreSQL 16 (with `pg_trgm`); host names are compose service names |
| `REDIS_URL` | `redis://redis:6379/0` | Celery broker, caches, rate limits, live run updates |
| `POSTGRES_USER`, `POSTGRES_PASSWORD`, `POSTGRES_DB` | `byop` | Used by the postgres container; keep in step with `DATABASE_URL` |
| `BYOP_POSTGRES_PORT`, `BYOP_REDIS_PORT` | `5432`, `6379` | Loopback ports published by the development override, used by `make test` |
| `TEST_DATABASE_URL` | `…@localhost:5432/byop_test` | Where the API tests find Postgres from the host; the database is created on demand |
| `MEDIA_ROOT` | `/data/media` (set by compose) | Where the local storage backend keeps files |

## Provider keys

All optional. See [providers](providers.md).

| Variable | |
| --- | --- |
| `OPENROUTER_API_KEY` | Language models (and speech) through OpenRouter |
| `OPENAI_API_KEY` | OpenAI language models and voices |
| `ELEVENLABS_API_KEY` | ElevenLabs voices |
| `KOKORO_BASE_URL` | A Kokoro-FastAPI (OpenAI-style speech) server. Empty: `make up-full`/`make up-kokoro` use the bundled one (`http://kokoro:8880/v1`), a minimal `make up` has none |

An OpenAI-compatible server (Ollama, LM Studio, vLLM, a gateway) has no variable: add it as a
connection under Settings › Integrations ([providers](providers.md#connections-any-openai-compatible-server)).

## Defaults for new shows

| Variable | Default | |
| --- | --- | --- |
| `DEFAULT_LLM_PROVIDER`, `DEFAULT_LLM_MODEL` | empty | Model given to a new show that does not choose its own (used only as a pair; `openrouter`, `openai` or `conn:<id>` of a connection) |
| `DEFAULT_SHOW_STYLE` | `news_briefing` | `news_briefing`, `conversational`, `deep_dive` or `interview` |
| `DISCOVERY_LLM_PROVIDER`, `DISCOVERY_LLM_MODEL` | empty | The model that searches the web for sources; empty uses the show's model, then the default above. On OpenRouter `:online` is added to the model id |

## Public routes

| Variable | Default | |
| --- | --- | --- |
| `PUBLIC_FEED_RATE_PER_MINUTE` | `120` | Requests per minute and client address to the public feed; over it the answer is `429` with `Retry-After`. `0` switches the limit off |
| `PUBLIC_MEDIA_RATE_PER_MINUTE` | `600` | The same for episode audio (a player that seeks makes several requests per episode) |

The client address is the last `X-Forwarded-For` entry nginx adds. Login has its own fixed limit of
5 attempts a minute ([security](security.md)).

## Sources and ingest

| Variable | Default | |
| --- | --- | --- |
| `SOURCES_ALLOW_PRIVATE_NETWORKS` | `false` | Feeds and pages are fetched from addresses users type in, so only public addresses are allowed. Set `true` for a feed on your own network. Link-local and metadata addresses are always refused ([sources](sources.md)) |
| `INGEST_FRESHNESS_DAYS` | `3` | How old a story may be to be collected |
| `INGEST_DEDUP_DAYS` | `14` | How far back a headline counts as already covered |
| `INGEST_TITLE_SIMILARITY` | `0.55` | Trigram similarity (0-1) at which two headlines are the same story |
| `INGEST_SOURCE_TIMEOUT_S` | `30` | Per source |

## Runs

| Variable | Default | |
| --- | --- | --- |
| `RUN_TIMEOUT_MINUTES` | `60` | A run with no progress for this long is failed by the reaper (needs the `beat` service) |
| `RUN_STAGE_MAX_RETRIES` | `3` | Retries of a stage after a temporary error |
| `RUN_REAPER_INTERVAL_S` | `60` | How often stuck runs are looked for |

See [runs](runs.md). The scheduler tick (every minute) is not configurable: [scheduling](scheduling.md).

## Voices and audio

| Variable | Default | |
| --- | --- | --- |
| `TTS_CONCURRENCY` | `4` | Speech requests at once (a provider can lower it for itself, e.g. Kokoro on a CPU) |
| `TTS_CHUNK_RETRIES` | `2` | Retries of one chunk before the fallback voice |
| `TTS_RETRY_BACKOFF_S` | `1` | First wait between retries, doubled each time |
| `AUDIO_TARGET_LUFS` | `-16` | Loudness of the episode (the podcast standard) |
| `AUDIO_BITRATE_KBPS` | `128` | MP3 bitrate |
| `AUDIO_CHANNELS` | `1` | 1 = mono (plenty for speech), 2 = stereo |
| `AUDIO_SEGMENT_GAP_MS` | `400` | Pause between lines |
| `AUDIO_TRANSITION_GAP_MS` | `900` | Pause between stories |
| `AUDIO_MUSIC_VOLUME_DB` | `-22` | Level of the music bed before it ducks under speech |

See [voicing](tts.md) and [audio](audio.md).

## Media storage

| Variable | Default | |
| --- | --- | --- |
| `STORAGE_BACKEND` | `local` | `local` (a volume) or `s3` (any S3-compatible service) |
| `S3_ENDPOINT_URL` | empty | e.g. `http://s3:9000` for the bundled service of `make up-full`; empty for AWS |
| `S3_PUBLIC_ENDPOINT_URL` | empty | Only if browsers must use another address than `S3_ENDPOINT_URL` |
| `S3_BUCKET` | empty | Bucket name (must exist for external services) |
| `S3_REGION` | `us-east-1` | |
| `S3_ACCESS_KEY_ID`, `S3_SECRET_ACCESS_KEY` | empty | Credentials (the bundled service uses the same values) |

See [storage](storage.md).

## Langfuse tracing

| Variable | Default | |
| --- | --- | --- |
| `LANGFUSE_PUBLIC_KEY`, `LANGFUSE_SECRET_KEY` | empty | A Langfuse project's keys; empty switches tracing off |
| `LANGFUSE_HOST` | `https://cloud.langfuse.com` | Where BYOP's containers reach Langfuse |
| `LANGFUSE_PUBLIC_URL` | empty | Where your browser reaches it, for the trace links (default: `LANGFUSE_HOST`) |

The self-hosted `langfuse` profile also reads `LANGFUSE_PORT`, `LANGFUSE_SALT`,
`LANGFUSE_ENCRYPTION_KEY`, `LANGFUSE_NEXTAUTH_SECRET`, `LANGFUSE_DB_PASSWORD`,
`LANGFUSE_CLICKHOUSE_PASSWORD`, `LANGFUSE_REDIS_PASSWORD` and `LANGFUSE_S3_ACCESS_KEY` /
`LANGFUSE_S3_SECRET_KEY`: see [langfuse](langfuse.md).
