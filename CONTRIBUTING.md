# Contributing

Thanks for your interest in BYOP! This is an early-stage project; the full
contributing guide will grow as the codebase does.

- Read [CLAUDE.md](CLAUDE.md) for the stack, layout and coding conventions.
- Read [docs/IMPLEMENTATION_WORKFLOW.md](docs/IMPLEMENTATION_WORKFLOW.md) for how work is picked up and shipped.
- Open an issue using the bug or feature template before starting larger changes.
- Run `make check` (lint + typecheck + tests) before committing.
- Commit messages follow `<type>(<area>): <summary>`, for example `feat(api): add shows CRUD`.
